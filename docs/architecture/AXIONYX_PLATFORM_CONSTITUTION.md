# AXIONYX PLATFORM CONSTITUTION

> "A system becomes real when it can be operated, secured, observed, maintained, and trusted by external users."

This constitution governs the `AXIONYX_PLATFORM`, ensuring that the architectural brilliance of the `AXIONYX_ENGINE` research lineage is preserved safely in production infrastructure.

## Rule 1: Immutable Evidence Lineage
Production systems cannot bypass evidence lineage. Every `Reality Crystal` and `Civilization Gene` must trace backwards to a specific, cryptographically hashed `Evidence Record`. The database must never contain orphaned knowledge.

## Rule 2: Uncertainty Exposure
Every intelligence output must expose uncertainty. A production API response or web interface cannot present a prediction or simulation as absolute truth. `confidence_score` and `uncertainty_range` are required fields in all reality models.

## Rule 3: Human Approval for Impact
Human approval remains required for high-impact actions. The platform must implement the Planetary Stewardship Council Interface for any system state change evaluated as C4 or higher. The platform provides decision support, not decision replacement.

## Rule 4: Coordination over Control
The platform optimizes coordination, not control. The `human_elements` schema is strictly used for capability discovery and collaboration matching. Humans are never ranked, scored, or treated as deterministic atoms.

## Rule 5: Reproducibility Pathways
Scientific claims require reproducibility pathways. An `Evidence Record` must expose its `methodology` clearly enough that a secondary, independent scientific node could reproduce the exact conditions.
