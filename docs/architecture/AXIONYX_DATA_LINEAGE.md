# AXIONYX DATA LINEAGE CONSTITUTION

> "Can every displayed insight be traced back to an origin?"

If the answer is no, the insight is discarded. AXIONYX is an intelligence infrastructure, not an oracle. It does not synthesize truth; it coordinates evidence.

## The Lineage Chain

Every `Reality Crystal` rendered in the AXIONYX Observatory must adhere to the following unbroken lineage:

1. **The Claim (Reality Crystal)**
   *   Must declare its `confidence_score`.
   *   Must explicitly list its `unknown_variables` via the Uncertainty Registry.

2. **The Backbone (Evidence Ledger)**
   *   Every claim must link to an immutable `Evidence Record`.
   *   The record must contain the `methodology` of measurement.

3. **The Anchor (Cryptographic Hash)**
   *   The Evidence Record must be cryptographically hashed at the time of submission to ensure the historical measurement has not been altered to fit a modern narrative.

4. **The Consensus (Scientific Review & Verification)**
   *   The Evidence Record must be cross-verified by an independent Institutional node or Human Element.
   *   Verification events must be permanently logged with the actor's identity and timestamp.

## UI Rendering Rules

The Observatory UI is strictly forbidden from displaying a Crystal's claim without simultaneously rendering its Evidence Lineage. A user must always be able to click through the crystal and read the laboratory methodology that produced it.
