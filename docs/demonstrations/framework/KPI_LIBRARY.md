# AXIONYX KPI Library

This library catalogs the standardized metrics displayed in the **Mission Control Before vs After** comparisons across all demonstrations.

| Operational Problem | KPI Metric | Legacy Baseline | AXIONYX Target |
| :--- | :--- | :--- | :--- |
| **Audit Preparation** | Effort to trace decision to source | 2-5 Days | < 12 Minutes |
| **Turnaround Time** | Delay identifying bottlenecks | End of Shift | Real-Time |
| **Compliance Risk** | Number of undetected standard violations | Unknown | 0 (Blocked at workflow) |
| **Asset Uptime** | Unplanned downtime due to drift | 15% | < 2% |
| **Trust Score** | Percentage of verifiable automated decisions | N/A | > 99.5% |
