# AXIONYX Capability Matrix

This document provides a transparent view of the maturity and readiness of the AXIONYX Ecosystem.

## Stability Levels
- **Level 1 (Permanent):** The Kernel. Never changes except in major v3 revisions.
- **Level 2 (Stable):** Canonical Domains. Evolve strictly through versioned Architecture Decision Records (ADRs).
- **Level 3 (Fluid):** Adapters. Fast-evolving integration layers.
- **Level 4 (Deployments):** Vertical products and client pilots.
