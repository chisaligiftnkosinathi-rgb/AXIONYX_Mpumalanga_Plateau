# AXIONYX 0.1: "The First Translation"
**Golden Demonstration Scope Constraint**

## Purpose
This document serves as the canonical record of the AXIONYX 0.1 Golden Demonstration. It defines precisely what this milestone proves, and intentionally constraints scope to prevent feature creep.

## What this demonstration PROVES:
* **Domain-First Architecture:** The ontology accurately models a complex physical reality (a Coal Laboratory).
* **Event Sourcing:** The system captures reality as a deterministic stream of immutable events.
* **Evidence Preservation:** Decisions are cryptographically linked to their source telemetry (e.g., ash content 12.4%).
* **Explainability:** The system translates automated threshold logic ("< 15%") into plain human language.
* **Replay Capability:** The system can step chronologically backward through time to reconstruct reality exactly as it occurred.

## What this demonstration INTENTIONALLY DOES NOT PROVE:
* **Live Laboratory Integration:** The data is a deterministic payload (`coal-sample-001.json`), not a live LIMS/SCADA feed.
* **Automated Actuation:** The system does not write back to or control external laboratory instruments.
* **Production Deployment Scaling:** This is a closed-world functional proof, not a load-tested benchmark.

## Rule of Engagement
**Sprint 2 is not platform expansion. It is proof.**
No new backend capabilities (AI agents, new databases, authentication improvements) will be added to the kernel to support this demonstration. The AXIONYX Computational Model is executed exactly as designed.
