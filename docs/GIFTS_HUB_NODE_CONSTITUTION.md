# Gift's Hub Node Constitution

## 1. Preamble
Gift's Hub is a constellation of human-facing intelligence nodes acting as sensors and translation endpoints for the AXIONYX Core. This Constitution defines the rules by which any node is permitted to enter, exist within, and communicate across the network.

## 2. What Qualifies as a Node?
A node is not simply a web application. A node is an intelligent gateway that:
- Captures human intent or physical reality.
- Maps that reality to verified capability.
- Generates structured opportunities or evidence records.
- Communicates back to the central AXIONYX Knowledge Graph.

## 3. Node Creation and Registration
Every node must be instantiated via the `node-factory`. Nodes declare their identity, purpose, inputs, and outputs through a `node.config.json` manifest. A node cannot operate unless its identity is successfully registered and verified by the Node Registry.

## 4. Earning Trust and Governance
Nodes do not have unconditional access to the Knowledge Graph or Opportunity Exchange.
- **Evidence Requirement**: Every relationship or signal generated by a node must carry evidence of its origin.
- **Consent Rule**: Nodes processing human data must secure explicit consent before interacting with the core engine.
- **Trust Scores**: Nodes accrue trust based on the accuracy and validity of the opportunities they generate.

## 5. Communication (The Dispatcher)
Nodes operate within a unified dispatcher environment (`giftshub-dispatcher`). This ensures:
- Secure, authenticated data flow.
- A single, verifiable telemetry stream.
- Seamless internal communication where an intent in one node (e.g., Curiosity) can route to another node (e.g., Materials) for resolution.

## 6. Evolution and Retirement
Nodes that successfully scale may graduate into dedicated microservices. Nodes that fail to produce verified evidence or whose purpose becomes obsolete will be deprecated, preserving their historical telemetry in the Civilization Memory.
