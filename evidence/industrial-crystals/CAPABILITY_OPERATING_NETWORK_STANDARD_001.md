# CAPABILITY OPERATING NETWORK STANDARD
**Crystal ID:** CAPABILITY_OPERATING_NETWORK_STANDARD_001
**Domain:** Human Coordination & Capability Governance
**Date Minted:** 2026-07-27

## The Constitutional Axiom
> "Infrastructure connects places. Networks connect intelligence. The capability is not the road; the capability is the living network using the road."

## The Core Principles

### Principle 1 — Weighted Evidence Consensus
Authority proposes, but evidence decides. Disputes are resolved via a weighted graph:
- **Scientific Layer (30%)**: Claims about reality require evidence.
- **Community Layer (25%)**: Capability must improve human life.
- **Industrial Layer (20%)**: Solutions must be executable.
- **Environmental Layer (15%)**: Long-term resilience matters.
- **Government Layer (10%)**: Coordination authority matters, but should not dominate.

### Principle 2 — Capability Succession & Lineage
A civilization fails when knowledge disappears. Capability becomes hereditary without being owned. The system must map Capability Lineage: Senior Expert ➔ Fellow ➔ Student ➔ Institution.

### Principle 3 — Capability Zoom
Networks must be mapped at two levels: The Ecosystem View (Professions / Nodes) for systemic understanding, and the Human Contribution View (Individuals / Laboratories) to preserve identity and memory.

### Principle 4 — Meaning Alignment
It is not enough to share resources. The network measures the *Meaning Alignment Index*—are different groups actually solving the same problem?
