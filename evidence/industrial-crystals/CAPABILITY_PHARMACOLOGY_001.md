# CAPABILITY PHARMACOLOGY #001
*The Civilizational Pharmacopoeia*

## 1. The Core Philosophy
A trusted drug is not defined by its power alone, but by its **evidence**—its known origin, mechanism, and side effects. An economy works exactly the same way. When an enterprise introduces a capability into the market without measurement or learning, it is releasing an unknown substance. Hidden capability creates risk. Measured capability creates trust.

## 2. The Patient Condition
The environment provides the initial conditions (e.g., Mpumalanga: coal, energy, mobility demand). The environment is not good or bad; it is the operating context. The *Intent* determines the diagnosis (Extraction vs Capability Development). The *Need* is the disease signal (an imbalance).

## 3. The Capability Medicine
A Tesla-like company is not a factory; it is a carefully controlled mixture.
- **Active Ingredient**: The core skill (e.g., Manufacturing).
- **Excipient**: The support network (Energy, Logistics, Capital).
- **Clinical Trial (Evidence)**: Quality tests, proving the capability works.
- **Pharmacovigilance (Learning)**: NC loops tracing failures into improvements.

## 4. The Classification System
- **Dangerous Compound**: Unknown Reality + Hidden Process + No Measurement. Creates systemic risk.
- **Trusted Medicine**: Verified Skills + Controlled Process + Quality Evidence. Heals the environmental imbalance.

The environment does not ask "Can you build a factory?" It asks "Can you understand the imbalance and create the capability that restores equilibrium?"
